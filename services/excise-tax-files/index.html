Excise-Tax Files · EDI, XML & CSV

Excise returns built from your ERP data, checked before you file.

Distributors of fuel, alcohol, tobacco, vapor products and other taxed goods file excise returns every month, and many agencies only accept them as data files listing every receipt and delivery. When that file is rebuilt by hand from bills of lading and invoices, it takes days and invites audit findings. We pull the detail straight from the system you already run, reconcile it, and hand you a file ready to submit.

What we usually find

  • Bills of lading and invoices retyped into a spreadsheet every month to build the schedules
  • Closing inventory that doesn't match next month's opening, found only when an auditor asks
  • Losses above the allowed limit with no record of why
  • Tax-paid credits claimed on purchases whose invoices don't show the tax separately
  • Tax-free sales to customers whose distributor permit has lapsed
  • One person who knows how the return gets built, and no backup when they're out

What we build

Schedule detail, built automatically

Receipts and disbursements extracted from your ERP, warehouse or dispatch system and mapped to product codes, schedule types, carriers and locations, instead of retyped each month.

Checked before it's filed

Opening plus receipts minus closing inventory reconciled against disbursements, with excessive losses, missing documents, unverified exempt buyers and gross/net mix-ups flagged for review.

The format each agency expects

An upload-ready file for the state portal, or a clean feed into the excise software or tax advisor you already use.

A record you can hand an auditor

Every line on the return traces back to the source document in your system, so supporting a filing is a lookup, not a search through file cabinets.

The formats agencies require

Excise returns are rarely a simple form. Most agencies want the transaction detail behind the totals, delivered as a structured file.

Example: one line of a state excise schedule

A state distributor return is typically backed by schedules of every receipt and disbursement for the month, often uploaded as a CSV or data file. Whether the product is fuel, alcohol or tobacco, each shipment usually becomes one row with fields like these:

Product code Schedule type Carrier name Carrier ID Mode of transport Origin Destination Bought from / sold to Their license or tax ID Date shipped Bill of lading or invoice number Quantity (gallons, cases, cartons)

All of it already sits in your ERP, dispatch or accounting system. The work is getting it out completely, coding it correctly and checking it before it goes to the state.

Common questions

Can you produce excise-tax return files from our ERP?

Yes. Distributors of fuel, alcohol, tobacco and other taxed goods often have to file excise returns as EDI (ANSI X12 813), XML or a state-specified CSV, built from bills of lading, receipts and sales. We extract that data from your ERP, reconcile inventory before anything is filed, and produce the file in the format each agency or your excise software expects.

Is this software or a service?

A service. We build and run the automation on your own data: the extract from your ERP, the reconciliation checks and the file each agency expects. There's no new software for your team to learn. If you already use excise tax software, we feed it clean data instead of replacing it.

Do you file the return for us?

No. We prepare and validate the data and produce the file. Your team or tax advisor reviews it, submits it and signs the return. We don't provide tax advice.

We already use excise tax software. Can you still help?

Yes. Excise software is only as good as the data fed into it. We build the extract from your ERP into your software's import format, with the same reconciliation checks, so the monthly load stops being a manual job.

Which taxes and states do you work with?

Fuel, alcohol, tobacco, vapor products and other excise taxes that require transaction-level data files, at the state and federal level. We start with the states you file in today and scope each one in the free assessment.
